# 整合流程（二期产物，一期占位）

> 定位：分模块拼装的"教科书级"参考 pipeline。代码从各条候选流程和做法登记册里取各家之长拼成，不照搬某一个仓库；每个模块都注明来源（来源仓库、文件、行号），整体能从头跑到尾，之后也能持续修改。

## 拼装原则（一期定下，二期执行）

1. 选每个模块时都记录：为什么选它、落选的候选有哪些、为什么落选（多个候选都留下记录）。
2. 模块之间的衔接遵守项目已有的约定：注释列固定格式、run_metadata 必填字段、seed 固定不再改。
3. 两条路线并行：基础流程（CPU 可复现）与规模化分支（WSL strict GPU）。
4. 实质内容有变更就升版本号并写进 CHANGELOG，不许悄悄改。
5. **输出层就是绘图呈现层**（2026-09-27 增）：V1.0 的出图模块按 [绘图呈现 README](../绘图呈现/README.md) 的 22 张图型卡选图型。每张图先想清楚要说明什么问题，再按卡内参考仓库与 zoro-figure 的固定规则实现；组织方式遵循 PATTERN-045/050/028/006 这几张做法卡的约定。
