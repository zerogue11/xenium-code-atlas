# 整合 pipeline（二期产物，一期占位）

> 定位：模块化组装的"教科书级"参考 pipeline——**不是复制某一仓**，而是从候选池与范式登记册取各家之长拼装，附完整来源映射（每个模块指到来源仓+文件+行号），可整体跑通、可持续迭代。

## 组装原则（一期立，二期执行）

1. 每个模块选用时记录：选它的理由、落选者及原因（多候选留痕）。
2. 模块间契约对齐既有纪律：注释列契约、run_metadata 必填字段、seed 冻结。
3. 基础流程（CPU 可复现）与规模化分支（WSL strict GPU）双轨。
4. 任何实质变更升版本号并写 CHANGELOG，禁止静默改。

## 文件

- `VERSION` — 当前版本号
- `CHANGELOG.md` — 版本历史
- （二期）`V1.0/` — pipeline 本体
