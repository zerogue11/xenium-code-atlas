    06 · 决策剧场指南¶

    Xenium 决策剧场把本库沉淀的主干七步工作流变成可以"亲手走一遍"的教学模拟器： 每一步 ≤3 个选项、全部收敛到主干——你选的是参数、图与代价，不是剧情。 模拟器入口：打开 SPA（推荐浏览器直接打开本链接；在线版与本地版内容一致）。

    一、玩法（60 秒上手）¶

    1. 选场景：首页 6 张卡——HCC / BRCA / CRC / UC / CROHN 五个公开关 + ZXM 本地专属关。
    2. 走主干七步：样本/panel → 装载 → QC → 归一化（固定默认，非决策点）→ 聚类 → 注释 → 下游。每步 ≤3 个选项，全部收敛到同一主干——差异在参数值、图与代价说明，不新建内容树。
    3. 踩坑事件：某些选择会触发坑事件卡（P-001~P-006），每条都带精读笔记 + 文件：行号双证据链，全部提炼自本库 27 份精读的「坑与限制」实读发现。
    4. 结算：文献镜像复盘表（你的选择 vs 库内文献路线）+ 坑事件结算 + 知识卡解锁（档案卡/精读/范式卡直达链接）。
    5. T2 交互：下游 C 选项有 canvas 散点播放器（3 万细胞抽样）——滚轮缩放、拖拽平移、按 cluster / 注释 / niche / 基因表达切换上色，数据全部来自预计算 JSON。

    二、诚实性三级标注（每一张图都带）¶

    级别 含义 站内呈现
    T1 真实数据预计算重算（seed 冻结，管线见 scripts/precompute_simulator.py） 图下方三行式标注：① 来源 ② 性质="真实重算" ③ 参考文献
    T2 文献结论参数化重绘（记录 DOI/PMID 溯源） 三行式标注 ②="文献结论重绘"
    T3 明确标注的示意图 SVG 右下角统一「模拟示意」角标

    版权红线：文献图一律重绘不搬运。所有 T1/T2 资产的标注登记在 docs/simulator/assets/<场景>/manifest.json，由 scripts/validate_scenario.py 强制校验。

    三、教学地图（关卡 → 本库锚点）¶

    关卡 数据模式 手册章节 核心范式卡 档案卡/精读
    HCC 肝癌 T1 全量（本机 V1 肝癌 162,628 细胞 + 健康肝对照 zarr） 01-基础范式主干 §1–§6 PATTERN-047（统一 QC 核心）、PATTERN-001、PATTERN-025、PATTERN-049、PATTERN-051 LIT-088 档案卡、精读 Moldia
    BRCA 乳腺癌 T1（10x 官方 FFPE Rep1，313 基因） 01 §1–§6 PATTERN-047、PATTERN-025 LIT-002 janesick（配准链路彩蛋在结算页）
    CRC 结直肠癌 T1 三级降级链（见下） 01 §1–§6 PATTERN-024（scVI→scANVI） LIT-072 crc-atlas、LIT-074 微转移
    UC 溃疡性结肠炎 T1-lite 结论模式 01 §2（统一核心诞生地） PATTERN-047 原产地 LIT-053 UCSF（论文已发表 JCI 2026）
    CROHN 克罗恩 T1-lite 结论模式（64.6 万细胞 5K 镜像） 01 §1（大样本复用）+ §5（迁移注释） PATTERN-025、PATTERN-026、PATTERN-024 LIT-066 Teichlab
    ZXM 本地关 T1 仅本机 04-实操测试计划（T3 递进扩样） 大样本 onboard 复用（候选流程池·官方线） 你的课题

    四关连读的设计意图：HCC 练参数直觉，BRCA 练 TME 结构，UC 练配对设计与诚实降级，CROHN 练大规模策略——主干七步是同一套，规模与组织变了，决策就变了。

    四、QC 三档的教学设计¶

    标准档 = PATTERN-047 统一核心（源 LIT-053 UCSF 仓）：min_counts=50 / min_genes=10 / 基因 min_counts=1 / min_cells=10。 宽松（≈½）与严格（≈2×）两档是教学设计值（用于呈现"参数→后果"因果），非库内推荐口径——写论文请用统一核心或按平台补丁层调整。

    五、CRC 关的三级降级链¶

    1. 首选：Nat Genet 2025（10.1038/s41588-025-02193-3）配套 Xenium 数据——核实结果：该文配套主线为 Visium HD（本库 LIT-026，GSE280318），无专设 Xenium 5K CRC 集。
    2. 次选（已采用）：10x Xenium FFPE Human Colorectal Cancer（Immuno-Oncology panel + custom add-on）做 T1。
    3. 兜底：T1-lite 结论模式（LIT-072 / LIT-074 结论重绘）。

    六、ZXM 本地专属关（仅本机）¶

    • 数据：你课题的完整 outs（新版式输出，1,196,822 细胞，onboard analysis/ 含 graphclust/UMAP/diffexp）。
    • 教学：大样本策略——复用 onboard 结果（先例：官方线 large_sample_reuse 模式），QC 三档在 3 万细胞抽样上重演（显式标注抽样口径）。
    • 资产：docs/simulator/assets/ZXM_local/——双保险不入公开：.gitignore 排除（main 分支）+ mkdocs.yml exclude_docs 构建层排除（gh-pages 分支）。公开站入口探测 404 即显示"本地版可用"提示。
    • 本地开启方法：C:\xenium_envs\xenium-cn-py311\Scripts\python.exe scripts\precompute_simulator_zxm.py 生成资产后，用 scripts\serve_simulator_local.py 起本地服务（build + 注入 ZXM 资产 + http.server），刷新模拟器首页即见"本地资产已就绪"。

    部署红线教训（2026-09-05）：mkdocs gh-deploy 从磁盘 docs_dir 构建，.gitignore 管不住部署——ZXM 资产曾被带上 gh-pages，已用孤儿提交强推清除。守门是 mkdocs.yml 的 exclude_docs，任何重新部署前确认该配置仍在。

    七、怎么跑的（复跑与校验）¶

    # 环境: xenium-cn-py311 (venv, C:\xenium_envs\xenium-cn-py311)
# 1) 预计算 T1 资产（HCC/BRCA/CRC; seed=0 冻结）
C:\xenium_envs\xenium-cn-py311\Scripts\python.exe scripts\precompute_simulator.py --dataset hcc
C:\xenium_envs\xenium-cn-py311\Scripts\python.exe scripts\precompute_simulator.py --dataset brca
# 2) T1-lite 文献结论重绘（UC/CROHN）
C:\xenium_envs\xenium-cn-py311\Scripts\python.exe scripts\precompute_lit_redraw.py
# 3) 剧本校验（schema/事件/资产/相对路径/三行式标注 五类检查）
C:\xenium_envs\xenium-cn-py311\Scripts\python.exe scripts\validate_scenario.py --strict
# 4) 本地预览（含 ZXM 本地关）
cmd /c scripts\setup_docs_links.cmd
uvx --from mkdocs-material mkdocs serve        # 站点预览（ZXM 资产被 exclude_docs 排除）
C:\xenium_envs\xenium-cn-py311\Scripts\python.exe scripts\serve_simulator_local.py
#   ↑ 玩 ZXM 关用这个：build + 注入 ZXM 资产 + http.server → http://127.0.0.1:8765/simulator/

# 5) 发布（exclude_docs 确保 ZXM 不上线；首次已孤儿强推清除历史泄露）
uvx --from mkdocs-material mkdocs gh-deploy

    中间缓存与原始数据在 F:\xenium数据\ov工作流测试\simulator_precompute\（不入 git）。
