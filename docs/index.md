# xenium-code-atlas · 从 91 篇文献的公开代码到能不断改进的教科书式做法

> **一句话**：把 72 个论文代码仓库按原始版本存档，每仓写一张说明卡，其中 27 个重点仓再做精读和代码质量检查；从中提炼大家都用的分析步骤和可以照搬的做法，最后拼成你自己的完整分析流程。
> 思路是**取其精华、去其糟粕、归纳共性、按场景重组、不断改进**，单选一个现成的 pipeline 并不够。

## 从哪里开始

1. **[开始这里](00-开始这里.md)**：本库怎么读、三阶段路线、环境前提。
2. **[分类分析报告（一期）](01_资料库/分类分析报告_一期.md)**：本期核心结论，包括共同的分析步骤、工程质量检查结果、目前缺什么与可改进处。
3. **[基础流程](01-基础流程.md)**：教科书主线的章节框架（候选版，二期定为正式版）。
4. **[做法登记册](02_工作流开发/做法登记册/README.md)**：46 张可直接照搬的模式卡。

## 本库的固定要求（摘要）

- 第三方代码只存本地镜像（`03_开源项目/`，不入公开仓），线上引用时给出「原仓库链接 + 锁定 SHA」；33/72 个仓没有 LICENSE，照搬前逐仓核对档案卡。
- 一切结论以实测为准，查不到标【待补充】。
- 候选流程并列登记，主线经你确认后定稿；实质变更升版本号。

完整规则见 [项目治理](05-项目治理.md)。
