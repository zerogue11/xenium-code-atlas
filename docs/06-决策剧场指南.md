# 06 · 决策剧场指南

> **Xenium 决策剧场**把本库沉淀的主干七步工作流变成可以"亲手走一遍"的教学模拟器：
> 每一步 ≤3 个选项、全部收敛到主干——你选的是**参数、图与代价**，不是剧情。
> 模拟器入口：[打开 SPA](simulator/index.html)（推荐浏览器直接打开本链接；在线版与本地版内容一致）。

## 一、玩法（60 秒上手）

1. **选场景**：首页 6 张卡——HCC / BRCA / CRC / UC / CROHN 五个公开关 + ZXM 本地专属关。
2. **走主干七步**：样本/panel → 装载 → QC → 归一化（固定默认，非决策点）→ 聚类 → 注释 → 下游。每步 ≤3 个选项，**全部收敛**到同一主干——差异在参数值、图与代价说明，不新建内容树。
3. **踩坑事件**：某些选择会触发坑事件卡（P-001~P-006），每条都带**精读笔记 + 文件：行号**双证据链，全部提炼自本库 27 份精读的「坑与限制」实读发现。
4. **结算**：文献镜像复盘表（你的选择 vs 库内文献路线）+ 坑事件结算 + 知识卡解锁（档案卡/精读/范式卡直达链接）。
5. **T2 交互**：下游 C 选项有 canvas 散点播放器（3 万细胞抽样）——滚轮缩放、拖拽平移、按 cluster / 注释 / niche / 基因表达切换上色，数据全部来自预计算 JSON。

## 二、诚实性三级标注（每一张图都带）

| 级别 | 含义 | 站内呈现 |
|---|---|---|
| **T1** | 真实数据预计算重算（seed 冻结，管线见 `scripts/precompute_simulator.py`） | 图下方三行式标注：① 来源 ② 性质="真实重算" ③ 参考文献 |
| **T2** | 文献结论参数化重绘（记录 DOI/PMID 溯源） | 三行式标注 ②="文献结论重绘" |
| **T3** | 明确标注的示意图 | SVG 右下角统一「模拟示意」角标 |

**版权红线**：文献图一律重绘不搬运。所有 T1/T2 资产的标注登记在 `docs/simulator/assets/<场景>/manifest.json`，由 `scripts/validate_scenario.py` 强制校验。

## 四、QC 三档的教学设计

标准档 = **PATTERN-047 统一核心**（源 LIT-053 UCSF 仓）：`min_counts=50 / min_genes=10 / 基因 min_counts=1 / min_cells=10`。
宽松（≈½）与严格（≈2×）两档是**教学设计值**（用于呈现"参数→后果"因果），非库内推荐口径——写论文请用统一核心或按平台补丁层调整。

## 五、CRC 关的三级降级链

1. **首选**：Nat Genet 2025（[10.1038/s41588-025-02193-3](https://www.nature.com/articles/s41588-025-02193-3)）配套 Xenium 数据——核实结果：该文配套主线为 Visium HD（本库 LIT-026，GSE280318），无专设 Xenium 5K CRC 集。
2. **次选（已采用）**：[10x Xenium FFPE Human Colorectal Cancer](https://www.10xgenomics.com/datasets/ffpe-human-colorectal-cancer-data-with-human-immuno-oncology-profiling-panel-and-custom-add-on-1-standard)（Immuno-Oncology panel + custom add-on）做 T1。
3. **兜底**：T1-lite 结论模式（LIT-072 / LIT-074 结论重绘）。

## 六、ZXM 本地专属关（仅本机）

- 数据：你课题的完整 outs（新版式，约 60GB，onboard `analysis/` 含 graphclust/UMAP/diffexp）。
- 教学：**大样本策略**——百万级细胞不复算，复用 onboard 结果（先例：官方线 large_sample_reuse 模式，1,196,822 细胞）。
- 资产：`docs/simulator/assets/ZXM_local/`（**.gitignore 排除，不入公开仓**）；公开站入口自动探测 manifest，404 即显示"本地版可用"提示。
- 开启方法：本机运行预计算脚本生成资产后刷新模拟器首页。

## 七、怎么跑的（复跑与校验）

```bash
# 环境: xenium-cn-py311 (venv, C:\xenium_envs\xenium-cn-py311)
# 1) 预计算 T1 资产（HCC/BRCA/CRC; seed=0 冻结）
C:\xenium_envs\xenium-cn-py311\Scripts\python.exe scripts\precompute_simulator.py --dataset hcc
C:\xenium_envs\xenium-cn-py311\Scripts\python.exe scripts\precompute_simulator.py --dataset brca
# 2) T1-lite 文献结论重绘（UC/CROHN）
C:\xenium_envs\xenium-cn-py311\Scripts\python.exe scripts\precompute_lit_redraw.py
# 3) 剧本校验（schema/事件/资产/相对路径/三行式标注 五类检查）
C:\xenium_envs\xenium-cn-py311\Scripts\python.exe scripts\validate_scenario.py --strict
# 4) 本地预览
cmd /c scripts\setup_docs_links.cmd
uvx --from mkdocs-material mkdocs serve   # → http://127.0.0.1:8000/06-决策剧场指南/
```

中间缓存与原始数据在 `F:\xenium数据\ov工作流测试\simulator_precompute\`（不入 git）。
