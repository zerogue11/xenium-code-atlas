# 01 · 基础范式主干（候选版 V0，二期终审定版）

> 主干 = 27 个精读仓 ≥24/27 出现的步骤 + 官方线/OV 线已验证实践。**这不是最终版**：二期以整合 pipeline V1.0 冻结；本页是它的章节骨架与学习路径。

## 主干七步（每步：做什么 / 跟谁学 / 借什么）

### 1. 数据读取与装载
- **做什么**：Xenium `outs/` → AnnData/SpatialData；大样本可复用官方 onboard 结果。
- **跟谁学**：官方线（`候选流程池/官方线_官方教程中文优化.md`）；OV 线 `ov.io.read_xenium`。
- **借什么**：平台差异止步于装载层（ist_benchmarking 做法，PATTERN-006）；ISS 图像链协议（PATTERN-016/017/018）。

### 2. 质控 QC
- **做什么**：细胞/基因过滤 + 平台特异指标；阈值显式可配置。
- **跟谁学**：UCSF colitis（跨平台"统一 QC 核心+平台补丁层"，PATTERN-047）；SpatialQM（指标定义层，PATTERN-001/002）。
- **借什么**：统一 QC 核心 50/10/1/10 基线 + 每平台补丁；指标单函数化。

### 3. 归一化 / HVG / 降维
- **做什么**：normalize→log1p→HVG→PCA；大样本走 GPU（OV 线固化参数）。
- **跟谁学**：官方线 notebook；OV 线 strict GPU 参数组。
- **借什么**：crc-atlas 的 `set_all_seeds`（PATTERN-023）；readiness 探测（OV 线）。

### 4. 聚类
- **做什么**：Leiden（CPU igraph fallback 记入 metadata）；多候选分辨率并行。
- **跟谁学**：官方线（cluster 编号与官方 graphclust 不可互换——已验证的坑）。
- **借什么**：多候选纪律：不同 resolution 并行、附简评、用户终审。

### 5. 注释（含去卷积）
- **做什么**：major/subtype 两级；注释列契约（major/subtype/confidence/evidence）。
- **跟谁学**：crohns 三段式（PATTERN-025/026）：单样本 celltypist→联合 scVI→子集精修；crc-atlas 的 scVI→scANVI 百万级路线。
- **借什么**：注释列契约（继承自 ov工作流测试，与文献最佳实践一致）；人工环节显式留痕（文献普遍断档，我们不跟风）。

### 6. 空间基础分析
- **做什么**：邻域富集/中心性/Moran's I（官方线已跑通的 Squidpy 模板）→ 进阶 A3 空间域。
- **跟谁学**：`run_v1_advanced_spatial_test.py`（官方线模板）；A3 模块地图。
- **借什么**：CellCharter 契约（obs 标签+邻接矩阵，PATTERN-025/027/028）。

### 7. 绘图与导出
- **做什么**：figures/ tables/ cache/ + run_metadata 三件套；图交付契约（PNG+PDF+CSV）。
- **跟谁学**：OV 线三件套；TRM"产数/出图双层"（PATTERN-045）。
- **借什么**：管线产数冻结对象、出图只读浅加工——外壳与内核分离。
