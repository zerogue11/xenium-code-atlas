# 01 · 基础流程（候选版 V0，二期经你确认后定为正式版）

> 主流程 = 27 个精读仓中 ≥24/27 都出现的步骤，加上官方线/OV 线已验证的实践。**这不是最终版**：二期会以整合流程 V1.0 定稿；本页给出它的章节框架与学习路径。

## 主流程七步（每步：做什么 / 跟谁学 / 借什么）

### 1. 数据读取与装载
- **做什么**：Xenium `outs/` → AnnData/SpatialData；大样本可复用官方 onboard 结果。
- **跟谁学**：官方线（`候选流程对比/官方线_官方教程中文优化.md`）；OV 线 `ov.io.read_xenium`。
- **借什么**：平台差异只在装载层处理（ist_benchmarking 做法，PATTERN-006）；ISS 图像链协议（PATTERN-016/017/018）。

### 2. 质控 QC
- **做什么**：细胞/基因过滤 + 平台特异指标；阈值显式可配置。
- **跟谁学**：UCSF colitis（跨平台"统一 QC 核心+平台补丁层"，PATTERN-047）；SpatialQM（指标定义层，PATTERN-001/002）。
- **借什么**：统一 QC 核心 50/10/1/10 基线 + 每平台补丁；指标单函数化。

### 3. 归一化 / HVG / 降维
- **做什么**：normalize→log1p→HVG→PCA；大样本走 GPU（OV 线参数已固定）。
- **跟谁学**：官方线 notebook；OV 线 strict GPU 参数组。
- **借什么**：crc-atlas 的 `set_all_seeds`（PATTERN-023）；readiness 探测（OV 线）。

### 4. 聚类
- **做什么**：Leiden（CPU igraph fallback 记入 metadata）；多候选分辨率并行。
- **跟谁学**：官方线（cluster 编号与官方 graphclust 不可互换，这是已验证的坑）。
- **借什么**：多候选要求：不同 resolution 并行、附简评、由用户确认。

### 5. 注释（含去卷积）
- **做什么**：major/subtype 两级；注释列固定格式（major/subtype/confidence/evidence）。
- **跟谁学**：crohns 三段式（PATTERN-025/026）：单样本 celltypist→联合 scVI→子集精修；crc-atlas 的 scVI→scANVI 百万级路线。
- **借什么**：注释列固定格式（继承自 ov工作流测试，与文献最佳实践一致）；人工环节明确留下记录（文献普遍没做这一步，我们坚持做）。

### 6. 空间基础分析
- **做什么**：邻域富集/中心性/Moran's I（官方线已跑通的 Squidpy 模板）→ 进阶 A3 空间域。
- **跟谁学**：`run_v1_advanced_spatial_test.py`（官方线模板）；A3 模块地图。
- **借什么**：CellCharter 固定格式（obs 标签+邻接矩阵，PATTERN-025/027/028）。

### 7. 绘图与导出
- **做什么**：figures/ tables/ cache/ + run_metadata 三件套；图交付固定格式（PNG+PDF+CSV）。
- **跟谁学**：OV 线三件套；TRM"产数/出图双层"（PATTERN-045）。
- **借什么**：管线产出的数据对象先固定，出图只做浅层加工、不回改数据；画图流程与数据流程分开。
