# 00 · 开始这里

## 这是什么

一个**活的**文献代码库：从 91 篇 Xenium/空间转录组文献里核验出 72 个公开代码仓库，在此基础上把"别人怎么分析空间数据"提炼成你自己的、能跑通、能不断改进的成套流程。

三条阶段路线：

| 阶段 | 内容 | 状态 |
|---|---|---|
| 一期 | 归档 72 仓 + 档案卡 + 27 仓精读 + 工程质量检查 + 46 张做法卡 + 本站 | ✅ 完成（2026-09-04） |
| 二期 | 提炼成套做法并定为正式版：共性框架 → 场景路线 → 整合流程 V1.0（经你确认后定稿） | 待开始 |
| 三期 | 实操测试：readiness→smoke（V1 肝癌回归）→逐步扩样（ZXM） | 待开始 |

## 怎么读这个库

```
想跑通一条基础流程   → 学习手册/01 基础流程 → 候选流程对比（官方线/OV线）
想学某个高级分析     → 学习手册/02 高级模块地图 → 对应分类的档案卡+PATTERN卡
想研究某个论文仓     → 档案卡（72张）→ S级再看精读笔记（27份）
想抄某个工程做法     → 做法登记册（PATTERN-001~053）
想加入新文献/新仓    → 资料库迭代更新SOP
```

三个关键认知（来自一期检查，详见[分类分析报告](01_资料库/分类分析报告_一期.md)）：

1. **共同的分析步骤高度一致**：读取→QC→归一化→降维→聚类→注释→绘图/导出，几乎人人都在做。这就是教科书式的核心步骤，有据可依。
2. **工程质量普遍不及格**（27 仓均值 8.3/14，达到工业水准的仅 11%）：文献仓的价值在**分析模块与路线**，这部分可以直接学；可直接复用的工程配套普遍缺失，配套部分要自己搭（二期核心工作）。
3. **硬编码路径、无 seed、无测试、import 副作用**是四个最常见的坑：任何"借鉴"先过这四关。
