# 02 · 高级模块地图（A1–A9）

> 每个模块给出**主推参考**（经过精读验证）和学习路径（先读档案卡，再读精读笔记，最后读做法卡）。模块定位见[高级模块说明](02_工作流开发/高级模块/README.md)。

## A1 细胞分割与重分割
- 主推：**hover_net**（工业级，12/14 分：工厂式延迟加载、strict 权重校验、内存感知调度），是分割模块的蓝本。
- 3D 配准+分割架构：mushroom（9/14，Spore 分治+统一网格）；ISS 从图像到对象的流程：Moldia 三件套（协议有价值、代码需重写）。
- 做法卡：PATTERN-013/014/015（模型加载/大图推理/分割产物交换）、011/012、016/017/018。

## A2 注释与去卷积
- 主推：**crohns 三段式**（先 celltypist，再 scVI，最后子集精修；Xenium 5K 数据上已验证过 64.6 万细胞的完整流程）。
- 百万级：crc-atlas（Nextflow，scVI/scANVI）；生态型注释：spatialecotyper（R 包范本，11/14）。
- 做法卡：PATTERN-023/024/025/026/021/022。

## A3 空间域·邻域·生态位
- 约定已定型：`adata.obs 标签列 + 邻接 csr 矩阵`；CellCharter 系参数几乎一致（依次跑 delaunay、aggregate、AutoK）。
- 最小实现参考：SPACE（500 行的 GAE 包，9/14，seed 管理满分）；跨模态恢复：spatialecotyper。
- 做法卡：PATTERN-027/028/031/025。

## A4 细胞通讯
- **72 仓集体缺位**（无专门仓），用生态工具 CellChat/LIANA+；空间特异验证可借 COPD 仓 LocalMoran.R 思路。
- **这是二期可改进清单里的第一位**。

## A5 亚细胞·转录本定位
- 方法包范本：drug2cell（scanpy 挂件：一次矩阵乘法算完全部基因群，结果存回 uns，PATTERN-033/035）；snp2cell（GRN 传播+置换检验，13/14 全库并列第一，PATTERN-034）。
- bin 级基准：SPATCH（价值在它的"测什么"清单，PATTERN-029/030）。

## A6 空间统计
- QC 指标层：SpatialQM（Moran's I/FDR/MECR 等，PATTERN-001/002）；平台对比阈值：ST_Comparison、ist_benchmarking。

## A7 配准·3D·多样本
- 官方配准流程：janesick（先用 Explorer 人工配准，再导出矩阵，最后做凸包过滤和 KDTree spot 插值，PATTERN-052/053）；人工环节是断点，二期可探索自动化。
- 3D 连续切片：mushroom；多样本整合：Harmony（ST_Comparison）/scVI（Kidney-Map）。

## A8 图像组学·多模态
- 管线工程：multiplex-imaging-pipeline（CLI+CWL+声明式门控 JSON，PATTERN-038）；从 H&E 图像推表达：ImagePseudo（思路可取，代码需要清理修复）。
- WSI 核分割+形态特征：sc_MTOP（与 hover_net 对照读）。

## A9 场景化应用范式
- **UC 课题第一参照**：UCSF colitis（9 数据集跨平台泛化，PATTERN-047）。
- 论文级全复现组织：TRM（产数/出图两层结构，用 pixi 做配套管理，PATTERN-045/046）；手册两条路线：tnbc-chemo（md 四段式验收，PATTERN-050/051）。
- niche 成套分析：Kidney-Map（先做微米半径的分平台换算，再做邻居计数，之后依次跑 KMeans、CellPhoneDB、Hotspot，PATTERN-048/049）。
