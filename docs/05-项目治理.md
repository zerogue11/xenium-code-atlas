## 站点构建复跑

```powershell
# 前置：docs/ 下两个 NTFS junction（fresh clone 后重建一次，cmd 管理员不需要）
cmd /c scripts\setup_docs_links.cmd

# 本地预览
uvx --from mkdocs-material mkdocs serve

# 构建并发布到 gh-pages 分支
uvx --from mkdocs-material mkdocs gh-deploy
```

junction 说明：`docs/01_资料库`、`docs/02_工作流开发` 指向仓库根的同名目录（内容零重复），已加入 .gitignore。
